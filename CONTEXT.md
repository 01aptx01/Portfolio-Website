# Portfolio

A personal developer portfolio showcasing end-to-end software engineering capabilities across frontend, backend, and systems development.

## Language

**Project Showcase**:
A curated selection of high-impact engineering projects featuring technical deep-dives, architecture context, live demonstrations, and source code.
_Avoid_: Portfolio item, gallery work, sample app

**Bento Project Card**:
A self-contained, responsive grid card displaying project imagery, architecture summary, tech stack badges, and actions to visit internal routes or external source code.
_Avoid_: Gallery tile, project teaser

**Internal Showcase Route**:
A dedicated same-domain page (`/projects/[slug]`) providing in-depth case studies, architecture diagrams, benchmark metrics, and engineering retrospectives.
_Avoid_: External link, pop-up only

**Paper Plane Centerpiece**:
The interactive visual focal point of the Hero section depicting a soaring geometric paper plane with stippled motion particles, symbolizing velocity, continuous learning, and software deployment.
_Avoid_: Generic stock vector, static banner

**Skill Group**:
A structured categorization of technical proficiencies organized by engineering discipline (Frontend, Backend & Systems, Database & Infrastructure).
_Avoid_: Tech list, buzzwords, tag cloud

**Experience Timeline**:
A chronological narrative of professional and educational milestones detailing contributions, engineering impact, and roles.
_Avoid_: CV list, history log, resume dump

**Dawn Pastel Editorial**:
The visual design language characterized by warm dawn-sky ambient gradients (soft peach, apricot, subtle lavender, cream), tactile stippled grain accents, crisp slate typography, and pill-shaped frosted glass interfaces.
_Avoid_: Stark white minimal, plain corporate theme, neon dark mode
